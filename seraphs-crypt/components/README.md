# The Seraph's Crypt — Copy-Paste Components

Each `.txt` file is a standalone, JanitorAI-friendly HTML block: inline styles
only (no CSS, no classes), starting at `<div>` and ending at `</div>`. Open a
file, copy everything, paste it into the profile editor. Stack as many as you
like in any order — they share the same black wrapper so they blend seamlessly.

Every section from `02` onward is a collapsible 🪽 seal (`<details>`): the
header bar is the summary, and pressing it opens the panel beneath.
